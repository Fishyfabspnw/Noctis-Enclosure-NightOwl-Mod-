# Changelog

Noctis release versions are independent of original NightOwl versions.

## v0.1.0-beta.1 — 2026-08-30

- Published the complete STEP assembly, including hidden geometry, and a source-visibility inventory.
- Added six 2560 × 1600 CAD renderings with improved lighting and the earlier GitHub background style.
- Added a beta download section, render gallery, known limitations, and feedback template.
- Added prominent NightOwl attribution, upstream GPL-3.0 license text, and modification notice.
- Documented two motor-reference validity failures and four hidden bodies, including an off-assembly fan body.
- Reframed unsupported thermal-performance statements as unvalidated design intent.

This release packages the existing model; it does not claim geometry repairs, fit validation, or completed thermal testing.
